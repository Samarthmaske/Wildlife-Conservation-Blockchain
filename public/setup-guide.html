🐾 BCTL - Database Setup Guide

Animal Conservation Database Configuration

Step 1: Start XAMPP Services

Open XAMPP Control Panel and ensure these services are running:

  • ✓ Apache
  • ✓ MySQL

By default: Apache runs on port 80, MySQL on port 3306

Step 2: Create Database

Method 1: Using phpMyAdmin (Easy)

  1. Open phpMyAdmin
  2. Click SQL tab
  3. Download and paste contents from config/schema.sql
  4. Click Go

Method 2: Using Command Line

mysql -u root < config/schema.sql

Step 3: Verify Database Connection

Step 4: Test API Endpoints

Database Configuration

Edit config/database.php if needed:

define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASSWORD', '');
define('DB_NAME', 'bctl_animal_db');

Quick API Reference

Action Method Endpoint
Get Animals GET db-api.php?action=getAnimals
Add Animal POST db-api.php?action=addAnimal
Update Animal PUT db-api.php?action=updateAnimal&id=1
Delete Animal DELETE db-api.php?action=deleteAnimal&id=1
Get Statistics GET db-api.php?action=statistics
